09 · EVIDENCEarXiv:2606.09498 · 2026-06-08

证据支持什么，又没有支持什么？

可以保留的结论

  • 同一个模型能提出有效的 runtime 修改。
  • 最小 edit + rollback 可降低明显回归。
  • 保留下来的修改对应具体失败机制。

仍然缺的证据

  • 所谓 held-out 每轮都参与 candidate promotion。
  • 尝试次数少，随机分数可能误导 gate。
  • 只覆盖三个工程化 benchmark。
