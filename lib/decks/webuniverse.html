WebUniverse · 如何验证08 / 16

检查器验证最终应用，三种任务用不同证据

细节需求可写脚本；高层需求通过浏览器探索；截图复现通过看图模型评分。

检查器可检查的内容保留条件
Browser scripts源码要求；Playwright交互与外观所有测试通过；复核完成无遗留问题
GUI agent只用浏览器；每测试记录 pass / fail / blocked所有测试通过
Visual judge成品与参考逐页面、逐视口比较每项 ≥ 0.75；页面不可达为0

生成测试时不读答案；失败测试若擅自增加要求，就重写测试并在未修改的应用上重跑。
