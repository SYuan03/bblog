02 · ACTORS先把名词对应到对象

这里没有一个神秘的“更强 teacher model”

同一份 Qwen3-8B 初始权重被放进不同的输入条件和更新角色。

Current student pθ

只看原题写一份完整回答，训练只更新它。

Harness Hθ

调用当前模型、检索样例或生成 plan，最后组装 teacher 的输入文本。

Frozen teacher pθ̃

初始 Qwen3-8B 的冻结副本；多看 harness 输入，判断下一个 token 的概率。

On-policy rollout

当前 student 此刻自己写出的回答。参数更新后，下一批回答也会改变。

Terminal context C

terminal 指流程末端，不是命令行；它是 harness 最终交给 teacher 的完整输入。

Confirmer / challenger

真实标签与初步预测（draft）相同或不同的历史样例，是数据行，不是 agent。

04 · SAME TOKENS真正的蒸馏合同

Teacher 和 student 不是在比较两份答案

两边都对 direct rollout 的同一位置给出“下一个 token 应该是什么”的概率。

Student input

原题 x + rollout 前缀

先考虑两种罪名

没有检索样例、draft 或 plan。

Teacher input

harness context C + 同一 rollout 前缀

先考虑两种罪名

能看到 plan 或检索样例。
