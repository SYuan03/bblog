02 · 最接近的对照Table 1；Appendix A.2

最接近 OPSD：改的是 teacher 多看到什么

student 是当前作答模型；teacher 是同尺寸的固定初始副本，负责计算概率反馈。两者重评 student 自己写出的同一份回答。

方法训练对象反馈来源
SFT，监督微调固定示范答案模仿示范；不是本文实测 baseline
GRPO当前模型的一组回答比较各回答的最终奖励
OPSD当前模型自己写的回答teacher 多看标准标签或标准解
OPHSD当前模型自己写的回答teacher 多看 harness 组装的材料

harness 是外部控制程序，安排检索和多次模型调用。Meta-Harness 等工作优化这个程序；本文优化模型权重，程序没有被搜索或学习。

SDPO 用执行反馈、OEL 用过去经验；CRISP 用简洁指令并每 50 步同步 teacher。本文不实测前两项。2 / 14
03 · 一次训练更新Figure 1；Eq. (3)；batch_builder.py

共用回答 token，不共用更新中的 teacher 权重

token 是模型预测的文字单位。teacher 参数固定；变化的是 harness 每次生成的输入材料 C。

① 当前模型生成原题 x → 回答 y

独立作答，不先用计划或检索改写 y。

② 另行运行 harness仍调用当前模型

取最后一次模型调用的输入消息，作为 C。

③ 比较下一 token 分布只更新 student

最终生成答案不替换 y；只要求其非空，未检查正确性。

student：当前参数 θ

看原题 x + y 的已有前缀，计算 pS，接收梯度。

teacher：固定初始参数 θ₀

看材料 C + 相同前缀，计算 pT，不接收梯度。

当前代码先 direct rollout，再 harness；teacher_prompt 动态组装，不是人工标注字段；默认任务分数只记录3 / 14
04 · 分类流程§3.3；draft_verify.py；_memory_bank.py

confirmers / challengers 是检索数据行

memory bank 保存之前的样例、真实标签和文本向量。按向量方向的相似度检索，不保证得到真正有用的证据。

先取最相似 5 条 → 当前模型生成 draft 标签 → 按标签分两组检索

confirmers，最多 5 条

与 draft 至少共享一个真实标签。不是要求整个标签集合相等。

challengers，最多 5 条

与 draft 没有共同标签。“不同标签”不代表构成有效反例。

原题 + draft 标签 + 两组样例 → verify 调用 → teacher 使用这次输入

正常两次生成、三次检索；表不足 10 条时只直接调用。当前批真实标签预测后才入表；测试默认 100 题一批，下一批能用先前测试题标签。

公开代码 test bank 按批更新；训练跨 epoch 不清表且无 self-index 排除，不能保证重复训练题不检索自身4 / 14

07 · 训练损失Eq. (3)；losses.py:54–67

整个词表 KL；公式方向必须直接核对

发布代码：KL(pS ∥ pT)
= Σ词表 token v pS(v)·[log pS(v) − log pT(v)]

论文写出的方向

KL(pT ∥ pS)，却称 reverse KL。代码另有 forward_kl 对应这个方向。

教学数值，不是实测

pS=(0.7,0.3)，pT=(0.2,0.8)：代码方向 0.5827；反向 0.5341。

在相同回答前缀上比较全部下一 token 选项，仅 student 反向传播。代码每个小批次合并有效回答 token 求均值，默认不做奖励加权或 token 子采样。

正文区分论文与实现；相同 token 序列不等于只比较采样到的单个 token；teacher 的梯度停止7 / 14
