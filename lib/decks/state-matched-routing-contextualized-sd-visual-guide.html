07 · 训练损失K3：采样 token 的分布差异估计

未匹配回合仍留在分母

pS、pT 是当前学生与教师的 token 概率；pOld 是生成这条回答时的学生概率。

δ = log pS − log pT；η = log pS − log pOld
d = exp(min(−δ,20)) − 1 + δ；ρ = exp(min(η,10))
L_SD = Σ(匹配 × 非特殊 token × ρ × d) / 全部原回答 token
L_total = L_GRPO + 0.01 × L_SD

推理和动作都训练；不是全词表 KL。pT、pOld 停止梯度，ρ 对当前学生仍可求导。

本文假设：两回合各 2 token，只匹配一回合，pS=pOld=.2、pT=.4。L_SD=2(1−ln2)/4≈.15343；用选中 token 作分母会翻倍。

Appendix A、skillsd_utils.py；公开函数 CPU 验算。示例概率不是模型实测7 / 13
