09 · EVIDENCEarXiv:2608.06301 · 2026-08-06

证据支持什么，又没有支持什么？

可以保留的结论

  • optimizer model 的影响大于外层 coding harness。
  • OpenCode 与原生 harness 都没有稳定取胜。
  • 昂贵 detailed trace 很少被 optimizer 有效使用。

仍然缺的证据

  • 每个配置只有两次 replicate。
  • GAIA seed 是 0 分 stub，应与 competent seeds 分开读。
  • optimizer 自身 token 只计量、不封顶。
