09 · EVIDENCEarXiv:2608.02276 · 2026-08-03

证据支持什么，又没有支持什么？

可以保留的结论

  • 专门训练的 engineer 比一次性 frontier editor 稳定。
  • 窄 action guard 也能改变最终结果。
  • pre-action 与 post-feedback hook 最重要。

仍然缺的证据

  • 主训练 reward 来自产生 failure packet 的同一 batch。
  • 补丁仍会造成局部 regression。
  • 跨 hook API 和大代码库尚未验证。
