02 · PART 0what is a scene program?

场景程序：执行 Python，生成可编辑的对象和相机

图片

只保留最终像素；换角度后被挡住的部分无法直接读出。

固定三维表示

mesh是顶点与面的表面网格；point map记录各像素对应的三维点。生成逻辑或对象身份可能缺失。

Scene program

程序创建对象、材质、灯光和当前渲染相机（active camera），执行后得到场景。Agent 可继续修改、渲染和查询。

08 · GEOMETRYvisible-surface reconstruction

几何评分：按隐藏 mask 划定对象的可见表面

配对与阈值

候选点投到参考图，按 mask 分区；不是对象名称配对，不额外对齐或缩放。

τ(g)=0.05×z(g)

参考深度2，容差0.1；误差0.12不命中（说明性算例）。

每对象 F1，再平均

Precision：候选点多少接近参考；Recall：参考点多少被覆盖。

Fₒ=2PR/(P+R)
Rᵢ=meanₒ(Fₒ)

参考有点、候选空则记零；参考采样后无点的对象不进分母。

只罚评分 mask 内的多余表面。所有 mask 外的额外几何不直接进入 R；遮挡后的背面也不在主指标范围。点数先全场景封顶 100,000，再按 mask 划分。

09 · APPEARANCEfresh evaluator rerender

外观重渲染再比较；无效产物留在分母里记零

Appearance A

评测器重新渲染场景，不直接用 Agent 提交的 final.png 计分。

同像素RGB最大误差≤30视为匹配；(20,25,29)过，(20,25,31)不过。

产物有效性（Validity V）

scene.blend、scene.glb和final.png有效，且主评测正常完成。V∈{0,1}。

Overall S

mean[V(R+A)/2]

每个尝试任务等权平均；交付或评测失败记零，不删除分母。

R是几何分，A是外观分；先算每个任务再汇总，不能默认拿所有均值直接相乘。

10 · HUMAN VALIDATIONcompatibility is not exact agreement

人工校准允许平局；83.7% 不是“指标判对率”

怎样标注

6 人各判断 40 组场景对，每组 4 个对象或区域：240 个人次场景记录，960 个局部判断。

几何题忽略颜色和光照；外观题只看圈定区域。先各做一个示范题。

怎样算一致

A 与 B 相反才算冲突；Tie 与 A、Tie 与 B 都兼容。人工兼容率 86.6%，并非三个标签完全一致。

指标分差<.05、或人工 A/B 票数相等时记 Both OK；人和指标兼容率 83.7%。

人工校准用 .05 的不确定区间；模型自评用 10⁻⁶ 的严格方向匹配。这两个百分比不能当成同一任务的准确率比较。

16 · LEGO-PLUGINthree targeted interventions

初始化、证据检查和版本回退分别处理三类轨迹失败

初始化

Enhanced Initialization：VGGT 估计竖直方向、房间边界和相机，给出投影范围与相对深度，不能当作真实米制尺度。

用观测检查修改

Grounded Refinement：SAM 3 划出对象区域，Depth Anything V2 估计深度；用范围、前后次序和亮度差检查修改。

保留或恢复版本

Version Control：修改前声明对象和验收条件；未通过时删除新增对象，恢复修改前的场景快照。

Agent 负责规划，通过 Blender MCP 编辑场景；插件只提供限定的测量、验证和受控修改操作。

17 · TRANSACTIONcandidate edit → commit or rollback

一次修改先声明边界，再改 Blender 场景，最后决定保留还是恢复

DECLARE声明修改对象

哪些对象能改，哪些须保护，允许改什么，以及必须满足的要求。

SNAPSHOT保存状态

位置旋转缩放、网格、材质、层级、相机与渲染设置。

VALIDATE检查证据

出现未声明改动、硬性要求失败，或证据缺失，就不接受修改。

DECIDE保留或回滚

最多 8 次受控修改（transactions）、2 次回滚，每个候选 2 轮修正。

场景变化会使旧验证报告失效；修改未处理完或渲染图未检查时，运行时检查会阻止 Agent 结束。

20 · VERDICTwhat is established?

可执行 scene program 已经能稳定交付；忠实的三维恢复仍是主要缺口

论文建立了什么

  • 单张图片到 Blender 程序的完整任务
  • 产物有效性、可见表面几何与外观三层评测
  • 对非单调编辑与失败自评的轨迹诊断
  • 冻结后的场景可用固定程序导出多种结果

证据边界

  • 输入图仍以模拟器渲染为主
  • 系统比较未统一推理预算与可见信息
  • 插件只在 42 道 Office 任务上验证
  • 研究代码与 evaluator 尚未公开，无法独立复现

当前 Agent 擅长交付一个可运行的 Blender 世界，但还不能稳定恢复图片背后的几何、相机和外观。
