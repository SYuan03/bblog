09 · EVIDENCEarXiv:2602.22480 · 2026-02-25

证据支持什么，又没有支持什么？

可以保留的结论

  • 工具任务改善较多，纯推理任务收益较少。
  • 不同运行找到完全不同的修复。
  • 外部权限能阻止 prompt 规则失守。

仍然缺的证据

  • optimizer token/API 成本未纳入同一预算。
  • 没有同预算人工优化器对照。
  • API 与 benchmark 版本漂移会改变结果。

10 · TAKEAWAYSarXiv:2602.22480 · 2026-02-25

追踪版本之外，还要追踪代价和退步

改掉异常 ≠ 做对题

11 个 AttributeError 消失，只有 3 个或 1 个任务转成 PASS。

同一版本可能反向迁移

Pawn 的 black_lake：GAIA +5.75pp，SimpleQA −17.78pp。

相同批数 ≠ 相同费用

Knight 的高分分支约耗四倍单题时间；公网答案和总成本仍需控制。

论文时期代码用 paper-v1；当前 v0.5 是重构版本。Terminal 每配置仅一次搜索，且同一批题参与优化与报告。
