09 · EVIDENCEarXiv:2602.22480 · 2026-02-25

证据支持什么，又没有支持什么？

可以保留的结论

  • tool-use 任务能从结构化优化中获益。
  • 不同运行找到完全不同的修复。
  • 外部权限能阻止 prompt 规则失守。

仍然缺的证据

  • optimizer token/API 成本未纳入同一预算。
  • 没有 human optimizer baseline。
  • API 与 benchmark 版本漂移会改变结果。
