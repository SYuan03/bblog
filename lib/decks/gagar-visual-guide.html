测试都通过了，RL 仍不知道哪个 patch 更值得学

GAGAR 在同一道 coding task 的 passing rollouts 之间加入质量排序，再重新分配正 advantage。

Binary reward

所有通过测试的 trajectory 得到同样 reward。一次精准修复和一次带有多余改动的修复没有区别。

Agentic grading

grader 联合查看 task、repository、trajectory、patch 与 test output，只给 passing candidates 排序。

Redistribution

低质量通过样本让出一部分 advantage，高质量样本得到更多训练权重。

02 · Training objectmixed-outcome group

训练单位是一组 16 条 rollout

动态采样只保留同时包含成功与失败的 groups。基础 advantage 是组内二元 reward 减去平均 reward。

INPUT同一 task

相同 repository 初始状态与任务要求。

ROLL OUT16 trajectories

每条包含 reasoning、tool calls、observations 与最终 patch。

RUN TESTSR ∈ {0,1}

基础 verifier 只判断可执行测试是否通过。

FILTER0 < R̄ < 1

全过或全错的 group 不用于这次组内学习。

Aᵢ = Rᵢ - R̄

06 · Constructed examplenot a released case

一个解释性例子：为什么必须重新分配，而不是直接打折

论文没有发布真实 group。下面只演示 Equation 2，不代表观察到的训练样本。

Group

4 条 rollout，2 pass + 2 fail，因此 R̄=0.5。两个 pass 的原始 advantage 都是 +0.5。

Quality factors

假设两个 passing patches 分别为 T1 与 T3，factor 为 1.0 与 0.2。

After redistribution

λ=1/(0.5×1.0+0.5×0.2)=1.667，两个 positive advantages 变为 0.833 与 0.167，总和仍为 1。

这是按论文公式构造的教学例。grader prompt、真实候选 patches 与逐项评分没有公开。

07 · Safeguardλmax = 1.5

论文的精确守恒公式与实际 bounded branch 有区别

Bound inactive

positive-advantage sum 保持不变，failed advantages 不变，group mean 仍为 0。

Bound active

λ 被截到 1.5，随后重新减去 group mean。排序保留，但 positive sum 与 failed advantages 不再严格保持。

λ_bnd = min(λ, 1.5)

可复用
