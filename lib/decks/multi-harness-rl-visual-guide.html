06 · 分组公式advantage：比组均值好或差多少

同一条 0/1 分，比较对象不同，相对得分就不同

AWithin(x,h,i) = [r(x,h,i) − μ(x,h)] / [σ(x,h)+ε]同题同接口的尝试互比，接口本身整体强弱造成的偏移被消掉。
ACross(x,h,i) = [r(x,h,i) − μ(x)] / [σ(x)+ε]同题四接口一起比较，强接口本身更容易成功的影响也进入相对得分。
v2 Equation 2；μ 为组均值、σ 为组标准差、ε 防止除零。相对分用于加权生成 token 的更新。

15 · 训练信号诊断只用一个相对分，能否猜出来源接口？

Cross 的相对分包含接口信息；两个对照都未单独隔离其影响

按任务五折验证

同题不能跨训练与测试折

分类器输入 advantage，预测 harness；减去同题内标签随机打乱的基准准确率。

Cross：30.63% − 26.15% = +4.48 pp；Within：+0.02 pp，区间含 0。关联不证明模型记住了接口。

辅助对照

信号数量与接口可预测性未分开

Coverage-matched 置零部分相对分，也降低接口可预测性。Residualized 减去其他任务的接口均分，但估计分布与训练分布不同，接口仍可预测。

两项较 Cross 的未见接口差值都不显著。

17 · 限制结论依赖当前数据、模型、接口和统计精度

低成功率、弱 SFT 起点和未公开材料，都限制结论范围

模型范围训练只有 Qwen3-8BPython 修复，成功率多为 1%–10%；没有高能力模型验证。
统计精度小差异仍与区间相容未见接口仅一个 weak-ReAct；不显著不等价。

18 · 结论对 Claude Code / Codex 相关训练研究的启发

原流程中变好、换流程仍变好、分组改变带来收益，要分别证明

本研究的证据

小幅训练增益，大幅接口差异

原接口的 Within / Cross 估计增益为 +0.48 / +0.77 pp；接口列均值差异 7.13 pp。

未见接口两种规则都未显著超过 SFT，Cross 未稳定超过 Within；没有证明多接口 RL 无用。

下一步对照

增加接口与持续在线训练

固定任务、预算、评分器，轮流留出不同接口；再比较持续采集下两种分组规则。

对照应验证非零信号数量与接口可预测性是否真的被单独改变。
