PART 0 · 运动从哪里来02 / 18

关键帧直接规定位置，刚体由物理引擎推进

Blender 的 Python 接口 bpy 创建几何、碰撞和关节。.py 是程序，.blend 是运行后保存的场景。

关键帧：指定物体在某一帧的位置。刚体模拟：设置质量、碰撞形状和约束，由重力、接触等决定后续运动。

任务允许合理初始驱动，禁止给下游零件安排独立的运动时间表。

import bpy

# 教学片段：让现有球参与刚体模拟
bpy.context.view_layer.objects.active = ball
ball.select_set(True)
bpy.ops.rigidbody.object_add()
ball.rigid_body.type = "ACTIVE"
ball.rigid_body.mass = 1.0
ball.rigid_body.collision_shape = "SPHERE"
bpy.context.scene.gravity = (0, 0, -9.81)

假设已有球对象；非完整脚本、非 benchmark 解法。论文要求 Blender 5.2，示例未在该版本运行。

JUDGE · 多级机械动作与传递08 / 18

每个组件一段；断链后独立运动不再得分

ECM（Executable Causal Mechanism）同时看前一级对后一级的机械传递，以及后一级完整动作。T2 顺序已给，T3-1 顺序须从帧推断。

initial → C19C1 完整动作
C1 → C28传递 + C2 动作
C2 → C32传递仅部分成功
C3 → C40断链；后来独立启动无效

ECM = (9 + 8 + 2 + 0) / 4 = 4.75。这是教学分数，非实测日志。N 个组件对应 N 段，不是 N−1。

REAL CASE · t3/task2/053 · 与论文 pp.20–21 对应09 / 18

B 先接近路口，A 先获得通行权

A、B 是运载物，各有目标体积；共享区边界在模拟前声明。被动 object_A 必须机械地控制 B 的进入。

进入：任意碰撞几何与共享区重叠。离开：全部碰撞几何清出。检查点：中心正向过内部平面。到达：整物体被目标包含。

初始 A、B 静止、在共享区与目标外。state_A0 / state_A1 是预先声明且不重叠的机械姿态范围。

REAL CASE · 规则规定过程，不能仅看最终位置10 / 18

A 完全离开，才机械地允许已运动的 B 进入

1 · B 开始接近必须早于 A 进入；B 仍在共享区外
2 · A 通过进入 → 检查点 → 全部离开
3 · 机构改变A 离开产生真实机械作用
4 · B 被放行进入 → 检查点 → 离开
5 · 持续保持各在目标内，机构处于 state_A1
E_start_B < E_enter_A
E_exit_A ≤ E_change_A1 ≤ E_enter_B
E_exit_A < E_enter_B
