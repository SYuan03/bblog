每次委派运行两棵候选子树，用同一份 rubric 评分，提交选中分支的完整状态。

04 · EXECUTION REWARDSection 3.2；Runtime/rubric/prompts.py

child 做任务；独立评分调用读取 rubric 和结果

执行路径

父 Agent 发起委派 → child 接收子目标、上下文和工具 → 执行并返回轨迹/状态。

child 不接收 rubric。它可以继续递归委派。

评价路径

委派前的信息 → 写 4–8 项 rubric → 固定这份标准 → 读取 child 结果评分。

训练 E：根用程序成败，非根用 0 至 1 连续分；只更新执行输出。

约束的是信息，不是硬性等待顺序。异步路径并发生成 rubric 与执行 child；RT 可先采集分支，但生成器仍只看父前缀和初始信息。

07 · DELEGATION REWARDSection 3.3；leaf_credit.py

一次委派覆盖多少叶节点，就分到多少结构奖励

rleaf(e) = root_success × |leaves under e| / |all leaves|
根任务成功某次委派覆盖 2 / 3 叶节点
