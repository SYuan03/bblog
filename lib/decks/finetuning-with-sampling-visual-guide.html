Off-policy expert

Projection sampling

最后仍使用标准 cross-entropy，不修改 optimizer objective。

02 · Target distributioninformation projection

理想目标：在所有正确答案中，保留 base model 原来的相对概率

p_C(x) = p_base(x) · 1[x ∈ C] / Z

C 是什么

与 expert trajectory 信息等价的集合。数学和 chemistry 可近似为 final answer 正确；medical 使用 semantic equivalence。

为什么难采样

直接 rejection sampling 等于不断让 base model 自己尝试。hard tasks 上可能几乎采不到正确 trajectory。

03 · Ideal algorithmblockwise MH

论文推导的算法是 Metropolis-Hastings

1Start

从正确 expert trajectory τ 开始。

2Cut

随机选择 token position m。

3Propose

把 prefix 与 expert solution 放进 prompt，重写 suffix。

4Accept

理论上按 target density 与双向 proposal ratio 随机接受。

5Repeat

逐 block、逐 MCMC step 移向 target distribution。
