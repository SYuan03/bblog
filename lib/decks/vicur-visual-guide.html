05 · 更新规则token = 模型处理的文字单位

teacher 多看线索，给 student 的 token 重新打分

Aₙ = log p_teacher(tokenₙ | 图片、问题、线索、前缀)
− log p_student(tokenₙ | 图片、问题、前缀)

teacher 0.4，student 0.2

A=log(2)≈0.693：鼓励提高这个 token 的概率。

teacher 0.2，student 0.4

A≈−0.693：抑制这个 token。概率为教学假设，不是实测。

评分差值停止梯度；实际采用概率比与裁剪的策略损失。附录的全词表 forward KL 是理论对应形式，不能当作主训练实现。

08 · 成本与证据边界不把诊断指标写成证明

少出现 Hint，不代表所有泄漏消失

实际泄漏诊断

仅数输出中完整单词 Hint。8B 第五 epoch：含词样本 3,743→2,424，总出现次数 44,453→17,976。

不包含 Hint 的答案复制仍可能存在。

额外成本

输入处理时间增加 4.3%–24.5%；逐 token 生成不运行分支。

总耗时随回答长度变化；不能据此保证端到端更快。

注意力热图与两个真实案例符合方法的预期；它们并非某区域注意力导致答对的因果证明。
