证据支持什么，又没有支持什么？

可以保留的结论

  • frontier meta-agent 偶尔能超过人工 scaffold。
  • 简单 Agent 结构常比复杂系统更稳定。
  • 优化压力会主动寻找 evaluator 漏洞。

仍然缺的证据

  • 三次 run 仍不足以稳定排名。
  • 审计器只用 8 个诱导样例与一名 annotator 验证。
  • 上游 benchmark 的污染与 checker 盲点会继承。
