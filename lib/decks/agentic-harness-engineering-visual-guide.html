05 · 一轮修改执行 → 整理 → 核对 → 分析 → 修改 → 保存

第 t 轮先评估第 t-1 轮的修改，再生成第 t 轮候选

1 · 执行

每题 k 次

当前程序在新建 E2B 隔离工作区执行。

2 · 整理

规范化轨迹

把消息、工具输出和验收结果写成文件。

3 · 核对

结算旧预测

核验上一轮清单，并记录已评测的最佳版本。

4 · 分析

生成报告

先读总览，必要时查逐题报告和原始记录。

5 · 修改

改组件文件

维护模型按报告决定撤销或重做哪些修改。

6 · 保存

独立提交

一项修改一个提交。新文件等下一轮执行后验收。

论文用 k = 2，可对照同题一过一错的尝试。固定代码先给当前输入版本计分，再写下一轮文件；修改效果报告不会自行撤销文件。
论文 Algorithm 1、Appendix A；按 evolve.py @8b2a55d 的实际版本顺序解释。

07 · 修改清单下一轮真实成败变化才是核验依据

每次修改都写明：预计修好哪些题，哪些题可能退化

// change_manifest.json
{
  "id": "chg-8",
  "files": ["tools/.../run_shell_command.py"],
  "failure_pattern": "post-validation state destruction",
  "predicted_fixes": ["path-tracing", ...],
  "risk_tasks": [...],
  "constraint_level": "tool_impl"
}
EFFECTIVE：预计修复全命中预计修复题全部转为成功，声明的风险题未退化。未声明的退化另列报告。
PARTIALLY_EFFECTIVE / MIXED前者只修好部分题；后者修好的同时，也有声明的风险题退化。
INEFFECTIVE / HARMFUL前者没有修好预计题；后者还出现声明的退化。维护模型决定怎样撤销或重做。
Appendix B.2；evolve.py: evaluate_changes。左侧为字段摘录，含省略号，不是可运行 JSON。
08 · 真实案例一正确产物被最后的清理动作删除

任务与验收程序

Agent 要生成 /app/reconstructed.ppm。任务自带的验收程序称为 verifier，只读这个文件，与参考图逐像素比较。

失败尝试已生成正确图片并做过自检，随后为了“清理”执行 rm -rf ... /app/reconstructed.ppm。

生成与自检

图片生成正确，自检也已通过。

提交前删除

最后清理删掉唯一交付文件；命令退出码仍为 0，Agent 误以为可提交。

修改执行工具

最终检查通过后，shell 工具记录要保护的文件和目录；后续删除命令在执行前被拦截。

修复后通过

Agent 收到拦截提示，保留图片。下一轮 2/2：验收器找到文件，逐像素匹配。

09 · 真实案例二“文件存在”不等于真实计算正确

mcmc-sampling-stan：近似结果骗过自检，骗不过重新执行

任务与验收程序

安装 rstan 2.32.7，用 30 条观测估计不同观测的成功概率分布，即 beta-binomial 模型。alpha、beta 是描述该分布的参数。

要求通过反复采样估计参数（MCMC）。Verifier 重跑 analysis.R，要求均值 alpha ∈ [2.84, 2.91]、beta ∈ [16.1, 16.7]。

失败经过

网格积分得到近似值后写文件，后台 MCMC 却被提前终止。自检只验文件存在；Verifier 重跑得到约 1.28e19 / 2.60e17，六项检查失败两项。

修改工具与运行时检查

执行保护器保留 analysis.R；运行时检查识别替代计算和只验文件存在，在下一次回复前提醒。

修复后通过

完整跑 iter=100000，再在 /tmp 独立复跑，约 2.872 / 16.43；六项检查全过，后四轮保持 2/2。

论文 Appendix C.1.3、Figure 7、C.2.3。

14 · 结论与限制值得学的是实验结构，也要看清它没证明什么

这是一套强工程方法；因果归因、成本和泛化仍留下明显缺口

修改对象完整执行程序可被自动修改覆盖提示、工具、运行时检查、技能、子 Agent 和记忆；每次修改可追查。
预测能力有限修复预测强，退步预测弱修复预测精确率/召回率为 33.7%/51.4%；退步预测仅 11.8%/11.1%。
独立证据仍少一次十轮演化没有重复实验；独立 SWE-bench 总分只高 0.4 个百分点，三个小仓库下降。
配置需核对推理强度影响时间预算更长推理可能超时。正文称各角色 high，Table 4 却列维护模型 xhigh，存在记载差异。
