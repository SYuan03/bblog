CodeCap-Bench · 具体算分08 / 15

只画出终态，动态关键点仍可得 0 分

对象对齐：并集可见帧

3 帧 IoU = 1, 0.5, 0
对象分 = (1 + 0.5 + 0) / 3 = 0.5

第 3 帧只在原视频可见，不能删出分母。对象完全缺失记 0。

动态评分：完整过程

原片：发射 → 碰撞 → 倒塌
成品：只展示倒塌后的结构
纯动态关键点得 0。
明显改变主节奏或同步关系，最多 2。

这是本文依据公开规则编写的算例，未运行官方评测器，也不是某模型的真实得分。保留分在表中用 0 至 100 尺度展示，不能把 Overall 当作 Static 与 Dynamic 的简单平均。

CodeCap-Bench · 结论15 / 15

能计算与重放的描述，有用也有明确边界

适用范围：规则化 2D 布局、几何形状、时间变化；尚不能推广到写实视频。
模型短板：时间顺序、过程与同步比静态外观更难。能渲染与保留内容分别报告。
可做对照：固定帧、tokens、工具与耗时，再隔离轨迹测量和视觉反馈的收益。
复现边界：项目页 Code / Dataset 按钮仍未启用；数据、官方 checker 与逐 case 评分尚无法核验。
