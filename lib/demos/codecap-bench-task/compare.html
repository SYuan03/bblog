这次实际执行的制作方式

1. 看输入视频

ffprobe 检查时长与尺寸，FFmpeg 抽帧，核对数字、红框位置、交换和停顿时刻。

2. 写 index.html

用真实数字字符串和矩形绘图指令重建画面；提供 duration、width、height、seek(t)。

3. 浏览器采帧

把 index.html 单独复制到临时目录。Chromium 以 300×180 打开；每次定位后截取一帧。

4. 编码成 MP4

576 张 PNG 按 24 fps 编成 H.264 视频。视频每一帧来自这个 HTML 的浏览器截图。

// render.mjs 中实际运行的采帧逻辑
for (let i = 0; i < 576; i++) {
  await page.evaluate(t => videoCompare.seek(t), i / 24);
  await page.screenshot({ path: framePath(i) });
}

// 执行命令（在本目录运行）
node capture.mjs index.html 6.416666667 frame.png
node render.mjs index.html reconstructed.mp4

// 渲染脚本调用的编码方式
ffmpeg -framerate 24 -start_number 0 -i frames/%06d.png \
  -frames:v 576 -an -c:v libx264 -crf 12 -pix_fmt yuv420p reconstructed.mp4
