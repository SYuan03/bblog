<p><strong>wrap_content</strong></p>
<ol>
<li><code>android:layout_width</code>：这个属性指定了视图的宽度。它可以采用不同的值，包括：
<ul>
<li><code>"wrap_content"</code>：视图的宽度将根据其内容自适应。换句话说，视图的宽度将根据其内容的尺寸来确定。</li>
</ul>
</li>
<li><code>android:layout_height</code>：这个属性指定了视图的高度。它可以采用不同的值，包括：
<ul>
<li><code>"wrap_content"</code>：视图的高度将根据其内容自适应。换句话说，视图的高度将根据其内容的尺寸来确定。</li>
</ul>
</li>
</ol>
<h3 id="FrameLayout-2">FrameLayout</h3>
<img lazyload="" src="/images/loading.svg" data-src="/posts/2023-Summer-Courses-%E7%99%BE%E5%BA%A6%E7%A7%BB%E5%8A%A8%E7%AB%AF/2023%E7%99%BE%E5%BA%A6%E7%A7%BB%E5%8A%A8%E7%AB%AFlec2-lec4/image-20230718154131995.png" class="" title="image-20230718154131995">
<img lazyload="" src="/images/loading.svg" data-src="/posts/2023-Summer-Courses-%E7%99%BE%E5%BA%A6%E7%A7%BB%E5%8A%A8%E7%AB%AF/2023%E7%99%BE%E5%BA%A6%E7%A7%BB%E5%8A%A8%E7%AB%AFlec2-lec4/image-20230718154606335.png" class="" title="image-20230718154606335">
<blockquote>
<ul>
<li>
<p>bias: 偏差，对相对位置进行调整，通常<strong>设置0到1之间的值</strong>，可以改变组件在水平或垂直方向上的偏移。如，<strong>水平</strong>偏差<strong>设置为0</strong>时候，组件靠近<strong>左侧</strong>约束，而<strong>设置为1</strong>时，组件靠近<strong>右侧</strong>约束</p>
</li>
<li>
<p>chains: 链，链的作用是在水平或垂直方向上分配组件的控件。可以设置链的样式，“spread”(均匀分布空间)、“spread_inside”(在组件内部均匀分布空间)、和"packed"(将组件紧密相连)</p>
<p><strong>spread</strong> 和<strong>spread_inside</strong> 的区别，以三个控件举例，<strong>spread</strong> 的第二个控件在中间，第一个和第三个则分别分布在左右<strong>剩余区域的中间位置</strong>，而<strong>spread_inside</strong> 的第二个控件在中间，第一个和第三个控件则分别<strong>紧贴父容器的左右两侧</strong></p>
</li>
<li>
<p>dimension ratio: 尺寸比例，设置组件的<strong>宽度与高度之间的比例</strong>。</p>
</li>
</ul>
</blockquote>

<h2 id="RecycleView：可滑动的列表UI组件">RecycleView：可滑动的列表UI组件</h2>
<img lazyload="" src="/images/loading.svg" data-src="/posts/2023-Summer-Courses-%E7%99%BE%E5%BA%A6%E7%A7%BB%E5%8A%A8%E7%AB%AF/2023%E7%99%BE%E5%BA%A6%E7%A7%BB%E5%8A%A8%E7%AB%AFlec2-lec4/image-20230720194951539.png" class="" title="image-20230720194951539">
<h3 id="基本组成">基本组成</h3>
<ul>
<li>
<p>Data：数据，需要展示的内容</p>
</li>
<li>
<p>RecycleView：一个可滑动的列表View</p>
</li>
<li>
<p>Layout：XML文件</p>
<blockquote>
<p>布局（Layout）：布局是指定义RecyclerView中每个项目的外观和结构的XML文件。它定义了表示列表中单个项目的视图的布局。</p>
</blockquote>
</li>
<li>
<p>Layout manager：负责处理View 的UI组件</p>
<ul>
<li>每个ViewGroup 都有一个LayoutManager</li>
<li>用于排列展示RecycleView 中的每一个item</li>
<li><strong>回收/复用</strong> 离开屏幕对于用户不可见的item</li>
<li>内置的布局管理器：
<ul>
<li>LinearLayoutManager(线性)</li>
<li>GridLayoutManager(网格)</li>
<li>StaggeredGridLayoutManager(瀑布流)</li>
</ul>
</li>
<li>可以自定义，继承：RecycleView.LayoutManager</li>
</ul>
</li>
<li>
<p>Adapter：将数据和RecycleView进行<strong>关联</strong></p>
<ul>
<li>
<p>负责提供数据和<strong>创建列表项(Item) 视图</strong>。</p>
<ul>
<li>比如：从数据中读取string, 将文字设置到item的view上</li>
</ul>
</li>
<li>
<p>数据和视图的媒介</p>
</li>
<li>
<p>当数据发生变化时，管理数据的创建、更新、添加、删除</p>
</li>
<li>
<p>RecyclerView.Adapter</p>
<blockquote>
<p>适配器充当数据和RecyclerView之间的桥梁。它负责为数据集中的每个项目创建和管理视图。它为每个项目视图创建视图持有者（ViewHolder），以便在用户滚动列表时高效地重用视图。</p>
<p>适配器对于处理数据的变化、更新、添加和删除非常重要。它在数据集发生变化时通知RecyclerView，以便RecyclerView相应地更新显示。</p>
</blockquote>
</li>
</ul>
</li>
<li>
<p>Viewholder：持有显示1个item的视图信息</p>
<ul>
<li><strong>负责保存列表项视图的引用，以便在需要时快速访问视图</strong></li>
<li>Layout在xml文件中进行声明</li>
<li>可以包含可以点击的元素</li>
<li>由LayoutManager进行摆放</li>
</ul>
</li>
</ul>

<h3 id="布局显示的过程">布局显示的过程</h3>
<ol>
<li>
<p>inflate</p>
<p>将XML格式的layout文件实例化为相应的View对象</p>
</li>
<li>
<p>measure</p>
<p>从根节点开始计算所有VIew的尺寸。会调用每个View的measure方法(可能会调用多次)。</p>
</li>
<li>
<p>layout</p>
<p>从根节点开始计算所有View的位置。(根据measure中确定的尺寸)</p>
</li>
<li>
<p>draw</p>
<p>绘制View</p>
</li>
</ol>
<h3 id="影响UI效率的因素">影响UI效率的因素</h3>
<ol>
<li>
<p>View太多</p>
<p>更多的inflate</p>
<p>更长的drawing时间</p>
</li>
<li>
<p>布局太深</p>
<p>更多的measure和layout</p>
</li>
<li>
<p>图片&amp;背景</p>
<p>图片资源过大</p>
<p>图片缩放耗时</p>
<p>过度绘制</p>
</li>
<li>
<p>频繁刷新UI</p>
<p>占用cpu资源</p>
<p>界面卡顿，交互反应慢，甚至造成ANR</p>
</li>
</ol>
<h3 id="过度绘制">过度绘制</h3>
<ul>
<li><strong>真彩色</strong>：没有过度绘制</li>
<li><strong>蓝色</strong>：过度绘制1次</li>
<li><strong>绿色</strong>：2次</li>
<li><strong>粉色</strong>：3次</li>
<li><strong>红色</strong>：4次或更多</li>
</ul>
